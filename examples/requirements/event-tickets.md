# Gather — event ticketing for independent venues

**Mode:** dynamic (web app with its own backend)
**Matches:** `specs/event-tickets.json` + `app-outlines/event-tickets.json` (drafted by Gemini on 2026-11-06, Story 23.0; the fake engine replays it)

Event ticketing for a city's independent venues. Attendees sign up, browse upcoming events (concerts, workshops,
talks, markets) by category and date, open an event to see its poster, venue, price and seats left, buy tickets and
see their tickets with a QR code reference. Attendees only see published events.

Organizers run the business side: they create events (title, poster, category, venue, start time, price, capacity,
status draft / published / cancelled), publish them, see ticket sales per event, check attendees in at the door and
follow a dashboard of tickets sold this week and revenue per event.

The two groups use the app very differently: attendees browse on their phones, organizers manage from a laptop.

Start with five venues and about ten upcoming events across the categories.

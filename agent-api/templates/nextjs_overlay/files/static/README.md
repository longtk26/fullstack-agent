# {{PROJECT_NAME}}

Static website generated by the Fullstack Generation Agent on Next.js (App Router, static export) and
shadcn/ui, following the `nextjs-skills` conventions. All content is baked in from `src/content/*.json`.

```bash
pnpm install
pnpm dev                   # http://localhost:3000
pnpm typecheck && pnpm lint && pnpm test && pnpm build && pnpm test:e2e
```

`pnpm build` writes the site to `out/`; any static host can serve it. Docker:
`docker build -t {{PROJECT_NAME_SLUG}} . && docker run -p 8080:8080 {{PROJECT_NAME_SLUG}}`.

Generated, do not edit by hand: `src/app/globals.css` (theme tokens), `src/config/site.ts`, `src/lib/forms.ts`,
`src/content/*.json`, `tests/e2e/*.spec.ts`. Regenerate them from the FrontendSpec instead.

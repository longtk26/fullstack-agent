# {{PROJECT_NAME}}

Web app generated by the Fullstack Generation Agent on Next.js (App Router), shadcn/ui, React Query, React Hook
Form + Zod and Zustand, following the `nextjs-skills` conventions. It talks to its backend only through the
client generated from the API contract (`src/lib/api/`).

```bash
pnpm install
cp .env.ex .env.local      # MOCK_TEST_API=true runs against the built-in mock API
pnpm dev                   # http://localhost:3000
pnpm typecheck && pnpm lint && pnpm test && pnpm build && pnpm test:e2e
```

- `MOCK_TEST_API=true`: requests go to the mock layer (`src/mocks/`, MSW) with the contract's example data.
- `MOCK_TEST_API=false` and `API_BASE_URL=<backend URL>`: requests go to the backend (it must allow this origin
  in `CORS_ORIGINS`). The values are read at runtime, so switching needs a restart, not a rebuild.

Docker: `docker build -t {{PROJECT_NAME_SLUG}} . && docker run -p 3000:3000 -e MOCK_TEST_API=true {{PROJECT_NAME_SLUG}}`.

Generated, do not edit by hand: `src/app/globals.css` (theme tokens), `src/config/site.ts`, `src/lib/forms.ts`,
`src/lib/api/*` except `client.ts`, `src/mocks/*.json`, `tests/e2e/*.spec.ts`. Regenerate them from the
FrontendSpec instead.

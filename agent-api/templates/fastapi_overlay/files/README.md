(hexagonal modules, SQLModel, Alembic, `@Transactional`, `BaseException` errors).

## Run with Docker

```bash
docker compose up --build
```

The API listens on http://localhost:8000 (OpenAPI docs at `/docs`). Migrations run on start.

## Run locally

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt -r requirements-dev.txt
cp .env.ex .env          # point DB_URL / TEST_DB_URL at your PostgreSQL
make mghead && make run
make test && make lint
```

Every request is logged as one JSON line (`"message": "request"` with method, path, route, operationId,
status and durationMs; no query strings or bodies).

Errors use one body shape: `{"error": {"code", "message", "details"}}`. List endpoints return
`{items, total, limit, offset}`.

# DevPulse

A news feed for software developers. Members sign up and get one feed of posts collected from engineering blogs and
communities. Each post has a title, a short summary, a cover image, the source it came from (for example "Vercel
Blog" or "Hacker News"), tags like React, Python or DevOps, a reading time in minutes, an upvote count and a
publish date. Members read the newest posts first, filter by tag or by source, upvote a post and bookmark it to read
later. They have a page with their bookmarks.

Sources have a name, a website and a logo. Editors add sources and posts and can hide a post that breaks the rules;
members cannot change posts.

Start with a few real-looking sources (Vercel Blog, GitHub Blog, Hacker News, Dev.to) and some recent posts.

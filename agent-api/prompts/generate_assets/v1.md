Write one SVG file per asset below, at exactly the path given, and nothing else: only these files are taken back

## Rules (every file is checked; a drawing that breaks one is sent back once, then replaced by a placeholder)

- Colours only as the theme's CSS variables, never hex, rgb or named colours: {% for token in tokens %}`var(--{{ token }})`{% if not loop.last %}, {% endif %}{% endfor %}, plus `currentColor`, `none` and `transparent`. The site's light and dark themes set
  these variables, so one drawing works in both. `opacity`, `fill-opacity` and `stroke-opacity` are fine.
  Gradients are fine when their `stop-color`s are variables; reference them as `url(#id)`.
- Flat shapes and paths: `rect`, `circle`, `ellipse`, `line`, `polyline`, `polygon`, `path`, `g`, `defs`,
  `linearGradient`, `radialGradient`, `stop`, `clipPath`, `mask`, `pattern`, `use` (only `href="#id"`).
- No text (the page has the words), no `<image>`, no embedded or linked raster images, fonts, `<style>`, scripts,
  event attributes, animation, `foreignObject`, external links or `data:` URIs.
- At most {{ max_kb }} KB and 2 000 elements per file. Keep it simple: a few dozen shapes read best at every size.
- Root element `<svg xmlns="http://www.w3.org/2000/svg" viewBox="…">` without `width` / `height`; no `<title>`
  (the site adds the alt text).
